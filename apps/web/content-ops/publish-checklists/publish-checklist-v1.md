# Publish Checklist v1

## SEO QA
- [ ] SEO title exists and is intent-aligned (no stuffing)
- [ ] Meta description exists and is human-readable
- [ ] Canonical URL is correct
- [ ] H1 matches article brief intent
- [ ] URL slug follows brief

## Schema QA
- [ ] BlogPosting schema present and accurate
- [ ] FAQPage schema only if FAQ is visible on page
- [ ] No schema field claims unsupported by article content

## Internal Linking QA
- [ ] Minimum internal links added per brief plan
- [ ] Funnel page link included
- [ ] Service page link included
- [ ] Related insights links included
- [ ] Reverse links requested from landing pages

## CTA QA
- [ ] Mid-article CTA present
- [ ] End-of-article CTA present
- [ ] CTA maps to intended funnel target

## Image QA
- [ ] Required evidence images present (per brief)
- [ ] File names follow naming standard
- [ ] Alt text is descriptive and factual
- [ ] No misleading or fake visual claims

## Local Intent QA
- [ ] Adelaide/suburb relevance is explicit
- [ ] Local context is useful, not keyword padding

## Cannibalization QA
- [ ] Compared against existing insights/service pages
- [ ] Primary keyword does not conflict with primary funnel page
- [ ] Anchor text diversity reviewed
